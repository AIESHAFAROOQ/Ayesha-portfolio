# Ayesha Farooq — Portfolio Website

A responsive one-page portfolio created from Ayesha's CV and tailored toward entry-level E-commerce Assistant opportunities.

## Files
- `index.html` — page content
- `style.css` — visual styling and responsive mobile layout
- `script.js` — mobile navigation and current year

## How to open
1. Extract the ZIP file.
2. Open the `ayesha_portfolio` folder in VS Code.
3. Double-click `index.html`, or use the VS Code Live Server extension.
4. Edit the text in `index.html` and colors/layout in `style.css`.

## Before sharing with employers
- Check your contact details.
- Add your LinkedIn URL if you have one.
- Add real links or screenshots for projects only when you have created them.
- The three project cards are clearly marked as practice samples. Replace them with your own completed samples when ready.
- E-commerce skills are described as beginner-level practice areas, not professional experience.
- This website uses Google Fonts when an internet connection is available; fallback fonts are included.

## Publishing
You can publish the folder using GitHub Pages or another static website host. No paid hosting is required for a basic static portfolio.
